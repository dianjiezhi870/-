# 黄水摄影

微信摄影分享小程序，AppID：`wx6436c6c484376d9b`。原生微信小程序 + 微信云开发，无需自建服务器。米白底、青蓝与青绿色，双列摄影瀑布流。

本仓库交付的是小程序源码和可部署后端，**尚未部署到微信云端、真机验收或审核发布**，目前没有有效的体验/正式小程序码。

## 已实现

- 每位微信用户均可发布 1–9 张照片，填写标题、正文、分类和地点，自动保存本机编辑草稿。
- 首页搜索、分类、最新/热门排序、分页浏览；详情多图预览、点赞/取消点赞、评论、分享、举报。
- 个人头像昵称、自己的作品与审核状态、获赞与评论统计、删除本人作品。
- 仅服务端配置的管理员可审核照片和设置首页歌曲；用户主动点击播放/暂停，离开首页停止播放。
- 文字内容安全检查失败时拒绝写入；照片经管理员审核后公开；未审作品仅作者与管理员可见。
- 云函数校验微信可信身份，数据库禁止客户端直接读写；点赞与计数通过事务更新，客户端传目标状态以支持重复请求。

## 先在微信开发者工具查看

1. 安装微信官方开发者工具，使用该 AppID 的开发者微信扫码登录。
2. 选择“导入项目”，目录选择本仓库根目录（含 `project.config.json`），AppID 已填写。
3. 直接编译即可查看明确标注的**本机演示模式**。无需填密钥或运行 npm 构建。演示作品和点赞评论仅保存在这一台设备，不能用于真实多人共享。

`miniprogram/config.js` 的 `cloudEnv` 为空时进入演示；填写真实环境 ID 后使用云端，不再展示或上传演示数据。演示用户默认不是管理员。不要通过改客户端 `isAdmin` 配置正式权限。

## 接入真实云开发并生成二维码

按 [部署步骤](docs/DEPLOYMENT.md) 完成云环境、数据库权限、云函数及管理员绑定，再进行两位普通用户和一位管理员的真机验收。

- **体验码**：开发者工具“预览”可生成开发预览码；上传代码、在微信公众平台设置体验版和体验成员后，可提供体验码。权限受微信的开发/体验成员规则限制。
- **正式小程序码**：完成公众平台名称、类目、隐私、主体资格及平台要求的配置，上传版本、提交微信审核，通过并发布后，由公众平台获取正式小程序码。最终名称是否可用以微信后台核准为准。

AppID 是项目标识，不是部署授权。此版本无需把 AppSecret 写入客户端。上传私钥、平台密码等凭据请勿发在聊天中或提交到 Git。

## 本地验证

使用 Node.js 22+（本次使用 Node.js 24）：

```sh
npm ci
npm run verify
cd cloudfunctions/api
npm ci
```

`npm run check` 检查 JS 语法、JSON、页面路由、事件处理、静态资源和主包源文件体积；`npm run compile` 使用微信维护的 `miniprogram-compiler` 编译全部 WXML/WXSS，并实际验证列表与权限分支的渲染树；`npm test` 执行业务、权限和页面控制器测试。业务测试使用内存事务模型与微信 API stub，不代表微信云数据库、微信媒体 API 或真机已经验收。

本地使用固定版本 `miniprogram-compiler@0.2.3` 中的 Linux WCC/WCSC 完成模板编译。该测试编译器较旧，发布前仍应在最新微信开发者工具中编译，并验证真机媒体、存储权限和云调用；本地编译不上传或发布。
