## 3. 隐私信息填写

在 `miniprogram/config.js` 填入真实运营主体与隐私咨询邮箱，并与微信后台声明保持一致。代码中的空字段是待配置项，不可将其视为已经完成隐私披露。

| 数据或行为 | 本版本实际情况 |
| --- | --- |
| 日期、正文、标题、心情、天气、标签 | 用户主动填写，仅用于当前设备保存、展示与检索 |
| 创建、编辑时间 | 保存记录时生成，用于草稿恢复与数据校验 |
| 字数、篇数、连续记录天数 | 基于本机记录在本机计算 |
| 剪贴板 | 用户点击复制备份并确认后写入，不读取 |
| 数据导入 | 用户主动在文本框粘贴备份，检查后新增缺失日期 |
| 登录身份、头像、昵称、手机号、定位、照片 | 本版本未接入相关获取能力 |
| 微信使用反馈 | 用户主动进入微信提供的反馈入口，遵循该入口说明 |

按后台当前表单与代码真实行为填写《用户隐私保护指引》。即使数据只在本地使用，也应如实告知处理方式，不要填写与功能矛盾的“完全不处理任何数据”。后台要求的具体条目以其当前表单为准。

本版本未调用读取剪贴板等隐私接口。如后续增加相册、录音、位置、头像等能力，必须重新核查数据类别、接口清单与授权流程；不能仅添加一个自行制作的同意弹窗后就视为已满足要求。参阅[微信隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。

## 5. 供审核人员体验的路径

1. 进入首页 → 记下今天 → 输入正文 → 选择心情、天气 → 保存。
2. 首页进入日记 → 继续编辑或删除。
3. 日历选择过去日期 → 补记 → 保存 → 返回查看日历标记。
4. 首页输入标题、关键词或日期，或选择心情筛选。
5. 我的 → 备份与恢复 → 选择月份 → 生成备份 → 主动确认复制。
6. 我的 → 隐私说明、使用说明、使用反馈或清空记录。

无需账号密码，不用获取微信昵称、头像或位置。首次打开无演示日记，应按上述路径建立一篇测试记录。
