# 拾日手记 · 微信原生小程序

用于每天记录生活的本机日记工具。AppID 已配置为 `wx6436c6c484376d9b`。

**项目目录：`shiri-diary`。在微信开发者工具里导入这个目录，不要导入仓库最外层；仓库最外层是另一个项目。**

## 可以做什么

- 每天一篇日记，可以编辑、删除和补记过去的日期。
- 手动选择心情、天气，添加最多 5 个标签。
- 按日期、标题、正文、标签搜索，按心情筛选。
- 用月历回看记录，查看累计篇数、字数和连续记录天数。
- 编辑时暂存本机草稿；离开时提示未保存修改，下次可继续写。
- 按月生成明文备份，主动确认后复制；粘贴备份恢复时跳过已有日期。
- 提供隐私说明、使用说明、微信反馈入口及清空本机记录的功能。

页面采用米白纸张、鼠尾草绿与手记风格。没有示例日记注入正式数据，首次打开为空白手记。

## 导入与运行

1. 下载仓库并解压，找到 **`shiri-diary/project.config.json`** 所在文件夹。
2. 打开微信开发者工具，以对该 AppID 有开发权限的微信账号登录。
3. 选择「小程序 → 导入项目」，项目目录选 **`shiri-diary`**。
4. AppID 应显示 `wx6436c6c484376d9b`；使用原生小程序模式，不需要创建云开发环境。
5. 点击「编译」。进入首页「记下今天」即可使用；补记从「日历」进入。

运行不需要 `npm install`，不需要服务器、数据库、云函数、域名或 AppSecret。`package.json` 只用于运行附带的离线测试。

## 数据与备份

日记与草稿以不同键保存于微信本地存储，不上传开发者服务器。天气与心情为手动选择。本版本不接入登录、定位、图片上传、广告、统计 SDK 或公开发布功能。

本机存储**没有额外加密，也不是永久备份**。换机、系统清理、删除小程序、重装微信等操作可能丢失记录。建议每月备份；备份文本包含正文，请存入自己的安全位置。主动使用微信反馈时，以微信反馈入口的说明为准。

恢复只新增缺失日期，不覆盖已经存在的日记。导入有中断回滚保护：若导入时写入失败，撤销本次新增；若小程序中途终止，下次启动会尝试回滚未完成导入。若存储持续异常，请先保留现有数据，不要直接清缓存。
