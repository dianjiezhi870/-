# 黄水摄影云函数

原生微信小程序云开发后端。`index.js` 只采用 `cloud.getWXContext()` 的可信 OPENID，不接受客户端管理员身份或作者身份。只有服务端云函数环境变量 `ADMIN_OPENIDS` 中的用户可以设置歌曲和审核作品，多个 OPENID 用英文逗号隔开。请勿把该变量放进小程序配置。

## 部署

1. 在 AppID `wx6436c6c484376d9b` 下开通微信云开发环境。
2. 创建以下数据库集合：`hs_users`、`hs_posts`、`hs_likes`、`hs_comments`、`hs_settings`、`hs_reports`。每个集合的自定义安全规则使用本目录 `database.rules.json`：客户端读写均禁止。业务操作均经云函数鉴权。
3. 在微信开发者工具中将本目录云函数 `api` “上传并部署：云端安装依赖”。依赖由 `package-lock.json` 固定，也可在本地运行 `npm ci` 校验。建议云函数 Node.js 18 或以上、超时 60 秒、内存 256 MB 或以上。照片由云函数顺序复制，避免一次把九张图片同时载入内存。
4. 为 `api` 配置环境变量 `ADMIN_OPENIDS`。管理员第一次登录“我的”页面后可取得本人 OPENID。随后在云控制台配置变量并重新部署/重启云函数，然后管理员重新进入小程序。不要让任何客户端接口修改此变量。
5. 保留 `config.json` 的 `security.msgSecCheck` 和 `security.imgSecCheck` 权限，并确认小程序主体具备内容安全接口调用资格。文字审核调用异常、超时、权限缺失都会拒绝发帖/评论/资料修改，不允许绕过检查。头像使用同步图片审核接口，要求小于 1 MB；若主体无法调用该接口，则不能修改头像，但仍可只修改昵称。
6. 云存储使用“所有用户可读，仅创建者可写”的创建者权限策略。客户端上传路径固定为 `uploads/<当前用户OPENID>/...`。作品提交后云函数将照片复制为服务端创建的 `submissions/<作品ID>/...` 待审快照；管理员审核通过后再次复制到服务端创建的 `published/<作品ID>/...`。头像只在同步内容检查通过后复制到 `avatars/<OPENID>/...`。服务端副本不属于客户端创建者，所有普通用户均不得覆盖或删除这些副本；必须真机验证该权限。不可用仅按路径中 OPENID 赋予写权限的规则，否则作者能替换已审核内容。不要将数据库或存储设置为公开写。
7. 建立下面的组合索引，然后在微信真机中执行本 README 的验证流程。

数据库用有界分页（每页 20 条、最大偏移 10000）。普通 feed 仅返回已审核作品，mine 仅返回调用者自己的作品。正则搜索对输入转义，按标题、描述、地点查找；随着数据增长可迁移到专门搜索服务。分页为偏移分页，浏览期间如果新作品/点赞改变排序，刷新可重新获取最新结果。

## 发布和审核

所有用户可上传 1—9 张 JPG、PNG、WebP 照片（单张小于 10 MB）提交作品，初始状态 `pending`。文字须通过微信内容安全检查；管理员人工查看不可被作者覆盖的照片快照后批准公开或拒绝。公开作品始终引用服务端创建的副本，用户修改原始上传文件不会改变待审或公开内容。复制与审核检查在数据库事务外进行，数据库保存失败会清理新副本；部分复制失败也清理已生成副本。删除副本失败只记录固定错误码，管理员可清理未被作品或资料引用的遗留副本。公开前只有作者和管理员可经业务接口读取作品；存储为所有用户可读，已知文件 ID 并不等同于私密文件，勿用于机密照片。公开后才允许点赞、评论。无需用户提供手机号或身份证资料。

输入上限：昵称 24 字、标题 40 字、描述 2000 字、地点 40 字、评论 500 字、歌曲名和歌手各 80 字。作者投稿只提交文字与上传文件，不允许改变审核结果。管理员更换歌曲时新上传文件须归本人所有；另一个管理员可复用当前已配置歌曲，修改标题或开关。

点赞支持 `post.like {id, liked: true|false}`，推荐传目标状态，这样重试不会反复翻转。旧调用 `{id}` 仍支持切换。点赞、评论及统计写入在数据库事务中完成。点赞文档以用户和作品的稳定摘要为主键，避免同一用户产生重复点赞。删除为软删除并撤销统计，用户不可删除其他人的作品。

举报以 `作品+举报人` 去重，存储在 `hs_reports`；管理员应在云数据库控制台定期查看 `status: pending` 的举报，按需删除对应作品并标记已处理。此版本暂未提供专门的举报管理界面。

## 真实环境验收

本地业务测试不能代替微信真机与云权限验证。部署后至少准备普通用户 A、普通用户 B、管理员 C：

- A 修改昵称、上传照片并提交，A 在“我的”可看到待审核作品；B 的首页与详情均不可访问待审作品。
- C 审核通过后，A/B 均能浏览，B 可以点赞、取消点赞和评论；两部手机重新进入后数量和评论一致。
- A 提交后覆盖原 `uploads/` 文件，待审快照内容应不变；A/B 尝试覆盖/删除 `submissions/`、`published/`、`avatars/` 的服务端副本必须被存储权限拒绝。审核后替换原上传文件不能改变公开作品。
- B 直接调用歌曲修改/审核/删除 A 的作品应返回权限错误；客户端伪造 `isAdmin` 无效。
- C 上传合法使用的音频，配置歌曲；A/B 首页点击播放、暂停，关闭开关后其他用户首页不再显示播放器。
- A 删除本人作品后公开 feed、详情均不可读；未审核通过的内容不出现在公开首页。
- 暂时取消内容安全接口权限时发布/评论必须失败；恢复权限后重新提交可成功。
- 头像审核拒绝或接口不可用时，公开头像和昵称均不变；仅修改昵称仍走文字检查。审核通过后头像引用服务端副本。
- 验证客户端直接数据库读写被拒绝，其他用户不能覆盖或删除 A 的存储文件。

不提供 AppSecret、上传私钥或伪造二维码。本地实现通过测试仅表示业务代码得到验证，云端部署、内容安全接口、真机上传和微信审核发布仍需该 AppID 管理员完成授权。
