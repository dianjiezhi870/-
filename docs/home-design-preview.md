# 首页静态设计预览

`home-design-preview.png` 是浏览器渲染的设计预览，**不是微信开发者工具或微信真机截图**。它不能证明小程序已编译、云功能已部署、微信审核通过或可扫码访问。

`scripts/design-preview.js` 读取实际首页 WXML、首页/全局 WXSS 和本机演示数据，将基础组件映射为 HTML 后使用 Playwright 截图。390 CSS 像素视口按真实比例将 1 rpx 转为 390/750 CSS 像素，输出为双倍分辨率。顶部明确显示预览标识；底部导航根据 `app.json` 构建浏览器近似样式。该转换器只用于当前首页静态设计，不模拟微信组件和事件。

生成命令：`node scripts/design-preview.js`。需要进程可访问 Playwright 模块与 Chromium；可用 `HS_CHROMIUM_PATH` 指定本机浏览器。脚本仅监听临时本机地址，结束后关闭，不提供公网预览或二维码。

本次预览检查：6 张演示卡片已渲染，图片全部加载，390 像素视口无横向溢出；已目视检查文字、卡片间距、封面和导航，没有发现遮挡或重叠。微信原生组件、样式兼容和触控交互仍需微信开发者工具及真机验证。
