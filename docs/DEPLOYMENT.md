# 从源码到“扫码进入”

当前已完成本地代码与自动化验证。云开发部署和微信正式发布需使用 AppID `wx6436c6c484376d9b` 对应账号的权限。没有绑定云环境时，本机演示与正式数据完全分开。

## 1. 创建并绑定云环境

在微信开发者工具导入仓库，打开“云开发”，为该 AppID 创建环境。复制**环境 ID**（不是环境名称或 AppID），填入 `miniprogram/config.js`：

```js
module.exports = { cloudEnv: '你的真实环境ID', cloudFunction: 'api' }
```

不要把密钥填在这里。环境 ID 本身不是密钥。微信云开发的资源计费、地域和开通资格以实际控制台为准。

## 2. 配置数据库、存储与云函数

1. 建立 `hs_users`、`hs_posts`、`hs_likes`、`hs_comments`、`hs_settings`、`hs_reports` 六个集合。每个集合的自定义安全规则使用 [database.rules.json](../cloudfunctions/api/database.rules.json)，禁止客户端直接读写。
2. 依照 [云函数说明](../cloudfunctions/api/README.md) 建立组合索引；首页最新/热门、分类、我的和评论列表都需要相应索引。
3. 云存储选择“所有用户可读，仅创建者可写”。上传原件属于上传者，提交与审批时由云函数生成的不可变副本由服务端持有；必须验证普通用户无法覆盖或删除这些副本。不要将存储写权限改为所有人。
4. 右键 `cloudfunctions/api`，选择“上传并部署：云端安装依赖”。云函数运行环境 Node.js 18+，超时建议 30 秒、内存 256 MB 起。保留 `config.json` 声明的内容安全权限。
5. 打开小程序，进入“我的”，复制自己的用户 ID。在**云函数服务端环境变量**设置 `ADMIN_OPENIDS` 为这个 ID，多位管理员用英文逗号分隔。重启/重新部署云函数并重新进入小程序，管理员会看到“管理空间”。不要在客户端保存管理员名单。

文字使用微信内容安全接口；头像会经过图片安全检查；照片由管理员人工审核。若微信接口权限不可用，相关提交会失败并提示，不会自动跳过审核。请根据云函数日志中的错误类型检查权限与部署，日志不应记录用户内容或凭据。

## 3. 验证真实多人共享

至少使用普通用户 A、普通用户 B、管理员 C 三个微信账号：

- A 上传图片投稿，A 的“我的”看到审核中；B 首页和直接详情均无法访问待审内容。
- C 查看完整图片后审核通过；B 能看到作品，点赞/取消点赞、评论。A/B 重启后数据保持一致。
- A、B 不能修改首页歌曲、审核作品或删除他人作品；直接调用接口伪造管理员标志也应被拒绝。
- C 上传有使用权的 MP3/M4A（不超过 20MB），设置名称、歌手和开启开关。其他用户刷新首页后可点播和暂停，离开首页停止。关闭开关后刷新应生效。
- A 可删除自己的作品，B 再读取应不可见；存储原文件不能被用来覆盖已提交或审核过的副本。
- 测试头像选择、昵称保存、草稿重进、网络中断、连续点击、无结果搜索、分页，以及相册选择失败后的重试。
- 检查数据库客户端直读/直写被拒绝，未授权存储覆盖被拒绝。

用户上传文件保存在云存储，软删除作品不立即物理删除照片和评论。应按运营需要设置保留期并清理无引用的原始上传文件，清理前核对数据库引用，避免误删。举报记录可在 `hs_reports` 查看并处理；本版未包含独立举报管理控制台。

## 4. 微信后台配置和发布

在微信公众平台配置名称“黄水摄影”、图标、简介、适合摄影分享及用户内容的服务类目、用户隐私保护指引和审核材料。实际可选类目、主体资格、备案及其他发布要求由微信后台确定。相册/摄像头仅在用户主动选择照片时调用，不读取地理位置、通讯录或手机号；地点为手工填写。

随后在开发者工具上传一个版本，公众平台设为体验版，可让体验成员扫描**真实体验码**。验收完成后提交审核，通过后发布，从公众平台下载正式小程序码，公众即可按微信规则扫码访问。

本仓库不会用普通网址二维码假冒小程序码；在获得实际微信预览/发布结果前，不提供虚构的扫码入口。仅有 AppID 无法替代账号授权、云环境和微信审核。

## 需要继续接入时提供的信息

- 云环境 ID（非密钥），以及页面参考项目的 GitHub/Gitee 地址。
- 管理员由本人在“我的”复制 ID 并在云函数控制台绑定；无需在聊天提供个人平台密码、AppSecret 或上传私钥。
